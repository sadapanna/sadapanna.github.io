How it works
  • Point / Line / Circle / Shape — tap to build. Hovering shows what you'd snap to: midpoints, thirds, intersections, "on circle"…
  • Move — drag any blue point; everything built from it follows. Double-click a point to rename it, or a graph to edit its formula.
  • Select things → actions appear. Click one object, then shift-click more. E.g. a segment → Midpoint, ⊥ bisector, ÷n; a point + a line → ⊥ / ∥ through it; 3 points → Triangle, Angle, Circle through 3; two curves → Intersect.
  • Shift-drag from a point — rubber-band a size, release, then pick Circle / △ / ◻ / ⬠ / ⬡ / n from the menu. The ⇧ Shift button (bottom-left) is the same as holding Shift — handy on touch.
  • Angle snapping — while drawing a line it clicks to 0°/45°/90° and to ⊥ / ∥ of lines on screen; the tag names the line (e.g. "⊥ to TU") and that line glows. Finishing on such a snap creates a linked ⊥/∥ — it stays true when dragged. Select it → 🔗 Unlink to break the link (works on any derived object). Dragged points snap to grid crossings; circle radii snap to half-units.
  • Graph — type f(x) like x^2/4 or sin(x). Points snap onto the curve; intersect it with lines or other graphs.
  • 📏 — toggle live sizes (lengths, radii) in grid units.
  • Shape tool presets — pick △ ◻ ⬠ ⬡ (or type n) in the row under the toolbar, tap a center, tap a corner. Drag any corner to rotate/resize it; drag the center to move the whole shape.
  • Dragging snaps too — a moving point grabs onto other points, midpoints, intersections, curves and the grid, with the same named tags as when placing.
  • Keyboard — tools: M/V move, P point, L line, C circle, S shape, G graph (or 1–6). Arrows nudge the selection (Shift = bigger steps) · U unlink · H hide · Del delete · Esc cancels a step · Ctrl+Z / Ctrl+Y undo/redo · + / − / 0 zoom.
  • Work saves automatically — ☰ opens your files. Everything runs offline.
